# SAP & enterprise integration

Positioning: pharma intelligence + operations layer; standalone or alongside SAP.
- S/4HANA: materials, suppliers, customers, purchasing, inventory, sales, finance
- Ariba: sourcing/supplier workflows; LIMS: samples/specs/results; MES: execution data
- CRM: commercial; IoT/SCADA + instruments: telemetry
- Mechanisms: REST/OData, webhooks, middleware; SAP Integration Suite / IDoc / BAPI / OData
- Stubs: `GET /api/v1/integrations/status`, `POST /api/v1/integrations/sync/{system}`
